# 2026-10-23

## S7 面板改成「按数据类型按钮读写」（仿 HslCommunication 那款工具）

原来的 S7 构造器是「操作 + 存储区 + DB + 地址 + 类型 + 数量 + 写入值」，用户想换成
「写个地址（M100），点类型按钮直接读/写，结果按 Dec/Hex/Bit 看」。

### 改动
- `Services/S7Comm.cs`：新增 `TryParseAddress(text, out area, out db, out byte, out bit, out error)`，
  支持 `M100` / `M100.3` / `MB100` / `MW10` / `I0.0` / `Q0.1` / `DB1.100` / `DB1.DBX100.3` /
  `DB1.DBW20` / `V100`（当 DB1）/ `T1` / `C1`；顺手加了 `FormatAddress` 回显。
- `ViewModels/S7ViewModel.cs`：整体重写。
  - 输入：`AddressText`、`ValueText`、`LengthText`（字符串长度）、`SelectedEncoding`（ASCII/UTF-8/GBK）
  - 输出：`ResultText`、`StatusText`、`SelectedResultMode`（Dec/Hex/Bit，另有 IsDecMode 等三个供 Radio 绑定）
  - 命令：`ReadCommand` / `WriteCommand`，**参数是类型名**（Bool/Byte/Short/UShort/Int/UInt/Long/ULong/Float/Double/String/Hex），
    按钮用 `CommandParameter` 传；一个命令顶 20 多个属性。
  - 8 字节类型（Long/ULong/Double）走 `BYTE×8` 收发，本地用 BinaryPrimitives 大端转换；
    字符串走 `BYTE×N`，按所选编码解。
  - 写：除 Bool 用 BOOL 外，其余统一以 BYTE 传输（避免 WORD/DINT 元素长度换算出错）。
- `MainViewModel.DecodeS7Response`：读应答把原始数据交给 `S7.OnReadResponse()`，
  写应答调 `S7.OnWriteResponse()`，错误类调 `S7.OnError()`；删掉了旧的 `RenderS7Value`。
- 界面：四行 —— 地址/值/长度/编码；读取按钮组 11 个；写入按钮组 12 个（多一个 HEX）；结果行（Dec/Hex/Bit + 只读框 + 状态）。

### 验证（`--s7-probe`，纯逻辑，无需 PLC）
- 13 个地址写法全部解析正确，非法 `X99` 被拒。
- 读帧类型码正确：BOOL 01 / BYTE 02 / WORD 04 / INT 05 / DWORD 06 / DINT 07 / REAL 08；
  Long/ULong/Double 用 BYTE×8，String 用 BYTE×10。
- 写帧编码正确：`-1234`→`FB 2E`，`-70000`→`FF FE EE 90`，`3.14`→`40 48 F5 C3`，`"ABC"` 补零到 10 字节。
- 应答解析：`FF B2`→-78 / `00 01 11 70`→70000 / `40 48 F5 C3`→3.14 / `01`→True；
  同一条数据切 Hex、Bit 都能正确重排。

> 注意：8 字节类型是「按字节读 8 个再本地拼」，PLC 侧只要是连续 8 字节即可；
> 真正的 LREAL（S7-1500 的 8 字节浮点）字节序与 .NET double 一致，可以直接这么读。

## 默认主题改为白色（Light）

- `SettingsService.AppSettings.Theme` 默认值 `Dark` → `Light`；`ThemeManager.Current` 初始值同步改 Light；
  `ThemeManager.Normalize(null)` 之前回落暗色，现在**回落亮色**（只有明确写 "Dark" 才是暗色）。
- `App.xaml` 里预置的调色板由 `Themes/Dark.xaml` 改为 `Themes/Light.xaml`，
  避免「窗口创建前」那一瞬闪一下暗色。
- 注意：**老用户 settings.json 里已经有 `"Theme": "Dark"` 的不会被改动**（那是显式选择），
  需要白色得点一次主题按钮切过去。

验证（`--theme-probe`，临时移走 settings.json 模拟全新安装）：
`ThemeManager.Current = Light`、`Normalize(null) = Light`、`Normalize("Dark") = Dark`、
`SettingsService.Load().Theme = Light`、merged = `Themes/Light.xaml` + `Themes/Styles.xaml`。
测试后已把用户原 settings.json 还原（cp 覆盖，别用 rm+mv——沙箱会拦 rm）。
